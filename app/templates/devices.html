How punches arrive

  • Polling: new events are downloaded from every enabled device every few minutes (set the interval in Settings) – by this server for direct devices, and by the bridge agent for bridge devices.
  • Push: optionally, configure the device to send events to {{ url_for('main.device_push', _external=True) }}{% if push_token %}?token=…{% endif %} for instant updates.
  • Duplicates are ignored, so both can run at the same time.
